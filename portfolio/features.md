# Features — ExploreNear

## Verified in the iOS 26 simulator

- Category chips for coffee, restaurants, parks and museums.
- Map with custom place annotations.
- Nearby places list with distance labels.
- Place detail with MapKit metadata and directions link.
- Fallback banner when using the default San Francisco coordinate.
- Light and dark appearance.

## Verification note

Unit and UI tests are authored and compile, but execution was skipped at the user's request.

## Physical-device checks

Real GPS, permission prompts and live local search results should be confirmed on a physical iPhone with internet access.
